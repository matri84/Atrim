# Atrim Framework

**ابزاری سبک برای ساخت خودکار پروژه‌های PHP**

Atrim یک نصب‌کننده تعاملی است که با دریافت چند ورودی از توسعه‌دهنده، ساختار اولیه پروژه PHP را به‌صورت خودکار ایجاد می‌کند.

### ویژگی‌ها
- نصب تعاملی از طریق ترمینال
- ایجاد خودکار ساختار پروژه
- سیستم مسیریابی
- مدیریت دیتابیس با PDO
- مدیریت نشست‌ها و فایل‌ها
- ابزارهای کمکی و اعتبارسنجی فرم

### پیش‌نیازها
- PHP 8.0+
- PHP CLI
- MySQL
